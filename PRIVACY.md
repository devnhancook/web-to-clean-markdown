# Privacy Policy - Web to Clean Markdown for LLM

**Last Updated: 2026**

## 1. 100% Local & Client-Side Execution
**Web to Clean Markdown for LLM** runs completely on your local device. 

- **No Remote Servers**: This extension does not maintain, connect to, or send data to any remote backend server.
- **No Telemetry / Analytics**: We do not track browsing history, clipped URLs, IP addresses, or article content.
- **No Third-Party Trackers**: Zero external analytics SDKs or advertising scripts are included.

## 2. Permissions Breakdown
- `activeTab` & `scripting`: Required to extract text and structure from the currently active web page only when clicked or shortcut triggered.
- `storage`: Used solely to save local user preferences (such as YAML frontmatter options and clip counter) inside `chrome.storage.local`.
- `downloads`: Required to save exported `.md` Markdown files to your local downloads folder.
- `clipboardWrite`: Required to provide the 1-click "Copy for LLM" action directly to your clipboard.

## 3. Data Ownership
All extracted text and files belong entirely to you and never leave your browser.
