## 🌟 为什么选择 Web to Clean Markdown & Study Vault？

当从现代网页复制文本或收集学习复习资料时，**超过 60% 的内容都是无用视觉噪音**（广告、Cookie 弹窗、侧边栏导航、相关推荐等）。直接复制粘贴到大语言模型（LLM）中不仅浪费昂贵的上下文 Token，还会破坏公式与代码排版。

**Web to Clean Markdown** 结合了超快 **网页剪藏器（<200ms）** 与 **内置本地学习档案库（Study Vault）**。

---

## ✨ 核心特性

- **🚀 一键 "Copy for LLM"**：一键复制带完整 YAML Frontmatter（标题、作者、原文链接、剪藏时间、预估阅读时间）的纯净 Markdown 到剪贴板。
- **📚 本地学习资料库（Study Vault）**：按学科标签（数学、物理、化学、语文、英语、技术）将文章与题目保存至本地专属私有资料库。
- **🔍 即时搜索与阅读模式**：按关键词快速检索，在弹窗内直接预览全文，无需新开标签页。
- **📦 "Download .md" 与全量备份**：保存单个 `.md` 文件或一键将全部资料导出为 JSON 备份。
- **🎯 智能区域选择器（Smart Selector）**：悬停并点击任意 DOM 容器，仅剪藏特定题目或公式片段。
- **🛡️ 100% 本地运行 & 隐私优先**：纯客户端运行，零遥测、零数据收集、无任何外部服务器中转。
- **⌨️ 快捷键支持**：按下 `Ctrl+Shift+K`（Mac 上为 `Cmd+Shift+K`）即可瞬间完成剪藏。

## 🚀 安装指南（开发者 / 加载已解压的扩展程序）

1. 克隆或下载本仓库代码：
   ```bash
   git clone https://github.com/devnhancook/web-to-clean-markdown.git
   ```
2. 打开浏览器的扩展管理页面：
   - Chrome: `chrome://extensions`
   - Edge: `edge://extensions`
   - Brave: `brave://extensions`
3. 开启右上角的 **开发者模式**（Developer mode）。
4. 点击 **加载已解压的扩展程序**（Load unpacked），选择 `web-to-clean-markdown` 文件夹。
